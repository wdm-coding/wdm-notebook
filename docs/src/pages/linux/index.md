# linux命令
```bash
1. ssh [用户名]@192.168.10.21 # 连接服务器
2. ls  # 查看当前目录下的文件
3. cd [目录名] # 切换到指定目录
4. ll # 查看当前目录下的文件详情
5. mkdir [目录名] # 创建文件夹
6. touch [文件名] # 创建文件
7. rm -rf [文件名] # 删除文件
8. mv [文件名] [新目录名] # 移动文件 或 重命名文件
9. vi [文件名] # 打开文件 vim编辑文件 i 进入编辑模式 esc退出编辑模式 :wq 保存并退出
10 grep [关键字] [文件名] # 搜索文件内容



```
