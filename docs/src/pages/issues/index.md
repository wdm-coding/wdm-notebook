# 关于微信小程序请求服务被雷池WAF安全拦截的问题，错误代码468

1. 错误原因：由于WAF的安全策略（如雷池WAF的挑战机制）将微信小程序内的正常请求误判为爬虫或机器人。
2. 解决方案：识别微信小程序的请求特征：通过User-Agent、Referer或自定义Header来区分小程序请求。在WAF中配置规则，对符合条件的微信小程序请求跳过人机验证。

具体操作步骤如下：
+ 在WAF中添加自定义规则，选择header匹配规则，字段：`User-Agent`，操作： `包含`，值：`MicroMessenger/`。
+ 选择header匹配规则，字段：`Referer`，操作： `正则`，值：`^https:\/\/servicewechat\.com\/.*`。
+ 将以上规则应用至白名单，确保微信小程序请求不被拦截。
