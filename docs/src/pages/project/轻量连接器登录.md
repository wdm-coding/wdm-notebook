### 轻量连接器登录

1. 身份注册-生成csrJSON-证书文件（pem）

2. 证书信息导入轻量连接器
  + 通过sdk自动导入证书信息
  + 手动导入证书信息(zip格式：身份凭证(ca.crt)、私钥(sk.pem))
  
3. 证书登录
  + 前端通过证书登录SDK 的 dnplogin.login(nodeId)唤起轻量连接器客户端
  + 选择对应证书登录
  + 轻量连接器或重定向一个地址（带有uuid）
  + 前端通过uuid 和 SDK的方法获取token
  + 使用获取的token调用后端接口进行登录


### 第一步 dnpRegister 注册身份

1. 参数
```ts
  const params = {
    certType: '1',
    subject: JSON.stringify([
      {
        name: 'O',
        value: '甘肃城市大数据运营有限公司'
      },
      {
        name: 'C',
        value: 'CN'
      }
    ])
  }
```
2. 获取到csrJson

3. 自动唤起轻量连接器客户端注入了一个身份（显示未注册）

### 第二步 导入证书dnpImportVc

1. 参数
```ts
  const params = {
     crt: crtJson, // 注册获取到的csrJson ？？
     certType: '1',
     apiUrl: 'https://localhost:3000/api' // 这个地址具体是什么？？
  }
```
2. 导入成功返回的res

### 第三步 dnpLogin登录认证

1. 参数
```ts
options: {
  nodeId: '12345678901234567890123456789012'
}
```
2. 自动唤起客户端，选择身份（必须是没有未注册标识的身份才可选）

3. 登录成功后跳转新链接，链接中包含uuid（链接地址从哪里设置的？？）

4. 前端从浏览器url中获取uuid

5. 前端通过uuid 和 dnp.fetchToken(uuid)获取token

6. 使用获取的token调用后端接口进行登录
