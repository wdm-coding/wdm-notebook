# 金融产品沙盘模拟

## 模拟客户群体池

### 客户字段
1. ID
2. 姓名
3. 手机号
4. 身份证号
5. 手机号在网时间：['不足三个月', '三个月以上', '半年以上', '一年以上', '五年以上']
6. 年龄
7. 性别，
8. 学历：['高中及以下', '大专', '本科', '硕士及以上'],
9. 客户类型：['个人', '企业'] (用于小微企业贷或者企业创业贷)
10. 是否小微企业：['是', '否'] (用于小微企业贷或者企业创业贷)
11. 企业健康度(%)：0-1(用于小微企业贷或者企业创业贷)
12. 收入等级：['低', '中', '高'] (后续计算贷款额度和还款能力)
13. 收入稳定性：['低', '中', '高'] (后续计算贷款额度和还款能力)
14. 信用等级：['A', 'B', 'C', 'D'] (用于信用评分模型)
15. 不良社交关系系数(%)：0-1 (用于反欺诈策略)
16. 人脸识别相似度(%)：0-100 (用于反欺诈策略)
17. ocr识别相似度(%)：0-100 (用于反欺诈策略)
18. 投资风险类型：['保守', '稳健', '激进'] (用于基金产品)
19. 健康状况系数(%)：0-1 (用于保险产品)
20. 信用评分：0-1000 (根据客户学历，收入等级，收入稳定性，信用等级，不良社交关系系数，人脸识别相似度，ocr识别相似度计算得到的信用评分)

### 参数影响模拟客户数据生成
1. 经济增长率（-5% 到 +10%）
 + 调高 模拟经济上行，客户收入普遍增加，贷款违约率自动下降，保险产品 与 基金产品 都会增加
 + 调低 模拟经济下行，客户收入普遍下降，贷款违约率自动上升，保险产品 与 基金产品 都会减少
2. 市场基准利率 / LPR（2% 到 8%）
 + 调高（加息周期）信贷产品的利差空间被压缩，学生如果定价过低就会亏损；债券类基金净值下跌
 + 调低（降息周期）刺激信贷需求，利好股市（基金涨），但保险公司投资端的收益率会下降。
3. 客户高信用资质占比 （生成的模拟客户数据中的信用等级占比变化）
4. 欺诈客户占比 （生成的模拟客户数据中的不良社交关系系数，人脸识别相似度，ocr识别相似度占比变化）

## 风控引擎配置

### 贷前准入模型字段
1. 黑名单策略库（多选,选中的表示需要检查的库）：['政务黑名单','征信黑名单','商采黑名单','行内黑名单','企业黑名单','负面行业黑名单']
2. 人脸识别相似度(%)：0-100 (设置多少表示需要达到的相似度，低于这个值的客户会被拒绝)
3. ocr识别相似度(%)：0-100 (设置多少表示需要达到的相似度，低于这个值的客户会被拒绝)
4. 是否校验手机三要素：['是', '否'] (校验姓名+身份证+手机号 是否匹配运营商数据)
5. 信用评分限制：0-1000 (设置多少表示需要达到的信用评分，低于这个值的客户会被拒绝)
6. 年龄区间：设置最小和最大年龄，客户年龄必须在这个区间内才会被允许申请贷款
### 贷中定价模型字段
1. 额度策略
2. 利率浮动
### 贷后管理模型字段
  设定逾期天数与处置动作的对应关系



1. 老师配置：客户画像参数 + 宏观环境参数 + 突发事件参数
2. 后台根据客户画像参数 生成 客户数据池。
3. 学生设计产品 + 配置风控策略 然后发布产品
4. 根据特定算法，后台模拟进行客户与金融产品的成交订单。
5. 根据特定算法计算改学生团队的经营数据。
